Privacy Policy

Last updated: November 18, 2026

What this app is

GTA VI Top Moments Autopilot is a personal automation tool used only by the owner of the GTA VI Top Moments channel to upload videos to the owner's own social media accounts.

Google / YouTube data

  • The app requests permission to upload videos to the owner's YouTube channel and to read the channel's name (to confirm the right channel is connected).
  • It does not read, collect, store, sell or share any data about other YouTube users or viewers.
  • The access token is stored privately as an encrypted secret in the owner's GitHub account and is used only to upload the channel's own videos.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services, see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/GTAMOMENTS/gta6-autopilot/issues.
