# GTA VI Top Moments — 24/7 Autopilot

> **Not a programmer? Start with [SETUP_GUIDE.md](SETUP_GUIDE.md)**: click-by-click setup, no code needed.

Fully automated faceless GTA 6 clip channel for YouTube Shorts, Instagram Reels, TikTok and X,
running free on GitHub Actions.

## Daily schedule (fully automatic)

**2 Shorts a day on every platform** (YouTube Shorts, Instagram, TikTok, X), **3 X text posts**, and **a long
YouTube video every 3 days**. Times are Turkey time (TRT); GitHub often starts scheduled runs 30-60 min late.

| Run at (TRT) | What |
|---|---|
| 15:10 | Long YouTube video, every 3 days (counted from the last one that posted), published once it passes QA |
| 16:50 | X text post (question / poll) |
| 19:40 | **Video A**: next format in the rotation |
| 22:10 | X text post (hot take / poll) |
| 01:40 | **Video B**: the format after it |
| 04:20 | X text post (daily recap) |

Change times in `config.json → schedule` **and** the matching `cron` lines in `.github/workflows/main.yml`.
If a Short slot posts nothing, the most viral famous-streamer clip goes out instead (not on Instagram).

**Formats rotate automatically** - every video run makes the next one in `config.json → formats.rotation`:
Top 5 funniest moments → Fast car chases → Top 5 things to do → Secrets & hidden details →
Crazy stunts & crashes → Trending topic → (repeat). All of them are narrated, so every Short can go to
Instagram (raw streamer clips stay off it). Each format has its own search queries, and the AI is told to make
exactly that video (countdowns say "Number five... number one"). Footage that can't honestly fit the format is
skipped (used only as a last-resort backup). Formats with `slot_only` (Money Tips, streamer reactions) are only
made on request (`format` input of a manual run).

**Editing for retention** (all automatic, no copyright):
- **Cold open**: every single-moment video starts with a 1.2 s flash of its biggest moment, then plays the clip.
- **Zoom punch-in + boom** on the big moment, **whoosh** on cuts (sound effects are generated by FFmpeg).
- Optional background music: drop royalty-free tracks in `music/`.

**Learns from views**: each run reads recent videos' YouTube views/likes/comments (free) and, once every
format has 2+ videos, mostly picks the best performing formats (25% of runs still explore the others).

**Captions per platform**: "GTA 6" + search keywords, numbered series ("GTA 6 Car Chases #4") in the YouTube
title, 3-5 targeted hashtags (YouTube ignores all hashtags if there are more than 15), and the ending question as
the first YouTube comment (needs the comment permission: re-run `tools/youtube_auth.py` once).

**Long YouTube video every 3 days** (`long_video.py`, slot `long_video` at 15:10 TRT): a 5-10 min 16:9 countdown of the
day's best GTA 6 stream moments (top Twitch streams, English Kick, X clip accounts). The AI reviews the clips in
batches (real GTA 6, no spoilers, nothing unsafe, hype), trims each to its best part and writes a label + one
narration line per moment. Edit: cold open of #1, title card + Fenrir line per moment (weakest first, #1 last),
whoosh between clips, subscribe outro, even loudness. YouTube gets a title with streamer names, chapters, credit links
for every clip, an auto thumbnail (custom thumbnails need a phone-verified channel) and a first comment. 2 Shorts a
day + a long video every 3 days stays well inside YouTube's free upload quota (about 6 uploads a day).

**Viral stream clips** (`stream_clips.py`; workflow `streams.yml` by hand only; the fallback for a Short slot):
finds the most-watched GTA 6 streams right now and posts their best clip with the streamer's **real voice**, big
word-by-word subtitles and a hook banner - no AI voice-over. Sources: top live streams on **Twitch** (needs free
`TWITCH_CLIENT_ID` / `TWITCH_CLIENT_SECRET`) and **Kick** (English, no key), big streamers' **YouTube** stream
recordings (cut at the "most replayed" peak) and **X clip accounts** (`stream_clips.x_accounts`, e.g. IShowSpeedHQ).
Viral = views per hour, with a separate bar per platform. Every clip passes the AI check (real GTA 6, no spoilers,
nothing unsafe, hype 7+). Posts to TikTok, Instagram and X, max 4 a day, 90 min apart, never the same moment twice.
News/official channels (IGN, Rockstar, PlayStation...) are never used.

**No spoilers**: story/walkthrough/cutscene/ending titles are blocked and the AI rejects any clip
that shows story spoilers.

**Human voice only**: every voice-over uses Gemini's "Fenrir" voice. If Gemini's voice fails
(quota/outage), the video is **not posted** rather than using a robotic voice
(`voice.robot_fallback: true` would allow the Microsoft voices instead).

## What each run does

1. **Finds recent footage from anywhere** (last 14 days, min 720p), mixing two types: **gameplay**
   and **stream moments** (viral Twitch clips, recorded streams, YouTube stream highlights with streamer reactions).
   Gameplay sources: gameplay walkthroughs, missions, story cutscenes, police chases,
   heists and stunts. It searches Dailymotion and YouTube with about 20 rotating queries, plus anything
   you drop in `/clips` or paste into `config.json → sources.extra_urls`. Official trailers are
   only a last resort.
2. **Filters out junk**: GTA 5 mods posing as GTA 6, fan "concept" trailers, AI fakes, leaks,
   reaction/news/talk videos, livestreams.
3. **Gameplay = "feature tour" shorts** (like the top GTA channels): 3 slices of a long gameplay video
   (YouTube "most replayed" peaks) are joined into a reel; the AI picks an angle (listicle "5 things GTA 5
   couldn't do", "how X works", or "first look"), chooses 6-12 different shots and narrates them in a
   casual human voice - every shot lasts exactly as long as its line (60-80 s videos).
   **Streams / short sources = "moment" shorts:** a ~2 min section, the AI picks the best ~1 minute.
   **The AI acts as the editor**: it watches the whole section and picks the most gripping 25–50 seconds
   (starting right before the action), with motion/loudness analysis as hints and as fallback.
4. **The AI judges the clip** (min 7/10 hype; a 6/10 clip is only used if nothing better is found) and (if Gemini is busy, a free OpenRouter/Groq/Mistral model checks frames of the clip instead) and rejects it if it isn't real GTA VI, has a facecam, or is boring.
   It then writes a banner, 3-5 short hype reaction lines timed to the big moments (not a narration), a YouTube title,
   captions and an X post.
5. **Renders a ~48 s 1080×1920 video**: blurred background, zoomed gameplay, wrapped hook banner, big
   word-by-word captions, human voice-over (Gemini TTS "Fenrir") over game audio, -14 LUFS.
6. **Publishes** through the cheapest working route per platform (see below), and records history
   so nothing is posted twice.

The run fails (red ❌ in Actions, email notification) if nothing could be posted. Each run's
summary page shows the source, AI verdict, script and post links.

## Publishing routes (free first)

| Platform  | Route (in order)                    | Cost |
|-----------|-------------------------------------|------|
| YouTube   | `youtube_api` → zernio → upload_post | **Free** (official API, 100 uploads/day) |
| Instagram | `zernio` → upload_post               | **Free** (Zernio: first 2 accounts free, unlimited posts) |
| TikTok    | `zernio` → upload_post               | **Free** (the 2nd free Zernio account) |
| X         | `x_api` → `x_browser` → zernio → upload_post | `x_browser` is **free**: a hidden browser posts with your login cookies (`X_COOKIES`). It breaks X's automation rules, so there's a risk of lock/suspension. The official API is paid (about $3/month) |

Change the order in `config.json → publishing.routes`. A provider without secrets is skipped automatically.

### YouTube one-time setup
1. https://console.cloud.google.com → new project → *APIs & Services → Library* → enable **YouTube Data API v3**.
2. *OAuth consent screen* → External → add yourself as test user → **Publish app** (status *In production*).
   In *Testing* status the token expires every 7 days.
3. *Credentials → Create OAuth client ID → Desktop app* → download the JSON.
4. On your PC: `pip install requests` then `python tools/youtube_auth.py path/to/client_secret.json`,
   log in with the account that owns the channel, and copy the 3 printed values into GitHub secrets.

## Checking your setup

Run the workflow with `slot = voice_samples` to hear the available voices (mp3s in the run's Artifacts),
then set `voice.gemini_tts_voice` in `config.json`.

Run the workflow with `slot = check_setup`. It tests every secret and shows a ✅/❌ table with fixes. It posts nothing.

## Running manually

*Actions → GTA6 Top Moments 24/7 Autopilot → Run workflow*:
- `slot`: what to run (`vertical_clip`, `x_video_clip`, `test_all`, or a text post type).
- `format`: only for test runs - `auto` (default) uses the rotation, or force one format to preview it.
- `dry_run` (default **on**): finds and renders the video **without posting**. Download it from the
  run's *Artifacts* to check the quality.

Locally: `python autopilot.py --slot vertical_clip --dry-run` (needs ffmpeg, plus a `.env` with the secrets).

## Quality checks before a video posts

Every Short goes through `qa.py`, **cheapest check first**. Once something already blocks publishing, the slower
and AI checks are skipped (they can't change the verdict, they only cost time and AI quota; `qa.fail_fast`):

1. **script**: the video says every line of the script the judge approved. If the voice-over had no room for a
   line, the script is rewritten shorter and re-rendered once.
2. **technical**: sync, silence, frozen / choppy / black picture, clipping.
3. **voice**: Whisper hears each line when its caption shows.
4. **picture**: an AI checks that each line matches what is on screen while it's spoken.
5. **AI editor**: an AI watches and listens to the whole video.

The `_QA.txt` report in the run's Artifacts lists the issues, the narration, how long each check took, and for
videos that pass, a **60-second human check**: hook, humour, promise kept, title. AI scores can't judge these
reliably; a weak Short scored 9/10 on 2026-11-23. Do a dry run and that check before trusting a new or changed
format.

## Tests

Offline (no secrets, no network, posts nothing). Needs ffmpeg:

```bash
python -m pip install -r requirements-dev.txt
```

```bash
python -m pytest -m "not slow"
```

That is the quick loop (~1 min). The full suite, which CI runs on every PR and push to `main`, adds end-to-end
renders and real-time download tests (~8 min):

```bash
python -m pytest
```

## Files

| File | Role |
|------|------|
| `autopilot.py` | entry point: maps each cron run to its slot, runs it, records history |
| `source_fetcher.py` | footage discovery, filtering, ranking, section download |
| `highlight.py` | finds the most action-packed seconds |
| `gemini_writer.py` | AI quality gate, scripts, captions, X posts (with fallbacks) |
| `ai_fallback.py` | free backup AIs (OpenRouter / Groq / Mistral), models auto-discovered |
| `video_processor.py` | TTS, word-timed captions, vertical render |
| `publisher.py` | YouTube API / Zernio / X API / Upload-Post with automatic fallback |
| `formats.py` | video format rotation (top 5 funny, car chases, secrets, ...) |
| `config.json` | schedule, formats, routes, search queries, filters, voice, style |

State (posted history + used sources) lives in the Actions cache (`queue/`), not in git.
